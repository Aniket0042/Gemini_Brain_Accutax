# MCP connector: 89 real questions, 10 Nov 2026

## What was run

All 89 cases in `backend/tests/data/real_questions.json` were sent through the MCP connector, the way Claude
or ChatGPT calls it: one `ask_accutax` call per case, with the case's organizations in `organization_ids`.
The calls went over Streamable HTTP with the MCP SDK client. The answer graded is the tool's text, which is
exactly what the host model reads.

- **Script:** `backend/scripts/eval/replay_mcp.py`, built on the existing replay harness: same cases,
  same Cube reference figures, same figure check, same sheet.
- **Where:** VM 106.51.80.81, against the live AI API on port 8011, asking as test user 5.
- **Settings:** real names on (`MCP_FULL_DETAIL_ORGS=*`), with the multi-organization and tool-budget fixes
  (`a6a07e1`, `bf1429b`).
- **Results on the VM:** `/tmp/mcp_eval/out/replay_mcp_20261110_141507.{json,md}`.
- **Cost:** $2.31 (2,310.7 credits in the usage ledger, 89 answers).

The changes between runs are the agent wording things differently, not the fixes:

- **r077 (TRN):** partial to pass. It now says it cannot check the organizations' own TRNs and offers the

- **r062 (cash flow):** pass to partial. It asks which alternative the user wants instead of showing the

- **r066 (3 bullets per company):** pass to partial. It asks what to cover instead of picking.

The 5 bare follow-ups still get a question back. The replay sends them as typed, so it cannot test the
fix, which asks the host to rewrite follow-ups into full questions. That needs a check in Claude itself.

## Found for the connector

1. **Follow-ups must stand alone.** The tool description should tell the host to put the metric, period
   and organizations into every question, because Accutax does not remember earlier calls.
2. **Charts and files are dropped.** An answer that offers a chart or a file should not say "attached
   below" when it was asked through MCP.
3. **Per-minute limit.** `USAGE_RATE_PER_MINUTE=5` refused 18 calls during the run. A host that asks
   several questions quickly will hit it; the refusal comes back as a clear tool error.
4. **Placeholder wording.** r079 asked the user to name the organizations "by their [ORG_#] name". The
   agent's privacy rules (PII_MODE=on) leak into the wording of a clarifying question. The portal has the
   same issue.
